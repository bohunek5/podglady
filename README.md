# Podglądy

Wspólny folder podglądów i materiałów do pobrania.

Strona: https://bohunek5.github.io/podglady/

## 1. Czek turystyczny

Materiały do Facebooka dla Stranda Residence: klasyczny post JPG, film MP4,
pionowa rolka, grafika kwadratowa i tekst do posta. Pliki publikacyjne znajdują
się w `1-czek-turystyczny/`; cały zestaw można pobrać jako ZIP.

## Kolejne zestawy

Każdy kolejny temat otrzymuje własny numer i katalog, np. `2-nazwa-tematu/`.
Dodaj link w nawigacji po lewej oraz nową sekcję lub stronę z podglądami.
Zachowaj istniejące adresy, żeby udostępnione linki nadal działały.

Strona jest statyczna. GitHub Pages publikuje katalog główny gałęzi `main`.
Nie wymaga instalacji ani kompilacji. Lokalnie można uruchomić:

```sh
python3 -m http.server 3012 --bind 127.0.0.1
```
